# 产品需求文档

## 1. 文档信息

- 产品代号：Stealth Reader
- 文档状态：Draft
- 目标平台：macOS 10.15+、Windows 10/11
- 第一优先平台：macOS Apple Silicon
- 第一阶段形态：本地优先桌面应用

产品名称、图标和视觉识别均为临时代号，进入公开发布前另行确定。

## 2. 背景与目标

用户希望在一个轻量、低干扰的桌面窗口中浏览网页和阅读本地资料。应用需要在正常使用与快速隐藏之间切换，并尽量减少工具栏、窗口边框和无关视觉元素。

第一阶段验证以下核心价值：

1. 网页与本地文档可以在同一应用中阅读。
2. 透明、置顶、自动隐藏和老板键足够稳定。
3. 小窗口下仍保持良好的滚动、缩放和文本排版体验。
4. 不登录账号也能完整使用核心功能。

## 3. 用户画像

### 3.1 碎片化阅读用户

希望在工作或学习间隙阅读小说、资料和长文，需要快速恢复上次位置。

### 3.2 小窗口浏览用户

需要将网页或文档保持在其他窗口上方，并控制透明度、尺寸和显示状态。

### 3.3 本地资料用户

拥有 TXT、EPUB 或 PDF 文件，希望离线阅读、搜索、建立目录并保存进度。

## 4. 核心原则

- 默认操作简单，高级能力逐步展开。
- 隐藏功能必须可恢复，不能让用户“找不到窗口”。
- 全局快捷键冲突时给出明确提示和替代方案。
- 网页内容视为不可信内容，不能直接访问桌面能力。
- 用户内容默认不上传，遥测默认关闭。
- 不声称所有网站均可完美兼容。

## 5. 第一阶段功能范围

### 5.1 桌面窗口

| 功能 | 优先级 | 验收条件 |
| --- | --- | --- |
| 窗口置顶 | P0 | 开关后在支持的平台保持在普通窗口上方 |
| 透明度 | P0 | 可在安全范围内连续调节并保存 |
| 迷你模式 | P0 | 一键缩小并可恢复原尺寸和位置 |
| 鼠标移出隐藏工具栏 | P0 | 移出后延时隐藏，移入可恢复 |
| 鼠标移出隐藏主体 | P1 | 支持延时和防误触保护 |
| 全局老板键 | P0 | 可配置显示/隐藏或退出，冲突时可诊断 |
| 托盘菜单 | P0 | 显示、隐藏、偏好设置和安全退出 |
| 登录启动 | P2 | 默认关闭，由用户主动开启 |
| 防截屏 | P1 | 以平台能力为准，并明确“尽力而为”限制 |

### 5.2 网页浏览

| 功能 | 优先级 | 验收条件 |
| --- | --- | --- |
| 地址栏与搜索 | P0 | 支持 URL 和搜索词，防止危险协议 |
| 多标签 | P0 | 新建、关闭、切换与恢复最近标签 |
| 前进/后退/刷新 | P0 | 状态与当前标签一致 |
| 历史记录 | P0 | 本地保存，可清除 |
| 收藏夹 | P0 | 支持新增、删除和打开 |
| 网页缩放 | P0 | 按站点保存缩放值 |
| 移动端模式 | P1 | 可切换 UA 与视口策略 |
| 自动滚动 | P1 | 支持速度调节、暂停和切换标签自动暂停 |
| 隐藏滚动条 | P1 | 对可控制页面生效，失败时不破坏页面 |
| 页面配色覆盖 | P2 | 仅在兼容站点启用，可快速恢复 |
| 下载管理 | P1 | 下载前确认路径，展示进度和失败原因 |

不承诺兼容 DRM 视频、受保护内容、特定企业登录、WebAuthn、安全插件、验证码拖拽和浏览器扩展商店中的全部扩展。

### 5.3 本地阅读

| 功能 | 优先级 | 验收条件 |
| --- | --- | --- |
| TXT | P0 | 支持 UTF-8、UTF-16、GB18030 编码识别 |
| EPUB | P0 | 支持目录、章节、字体和主题 |
| PDF | P0 | 支持缩放、翻页、目录和进度 |
| MOBI/AZW3 | P1 | 解析失败时提供明确提示 |
| 书架 | P0 | 添加、移除、分类和搜索 |
| 阅读进度 | P0 | 每本书独立保存并自动恢复 |
| 全文搜索 | P0 | 不阻塞主界面，可取消 |
| 阅读样式 | P0 | 字体、字号、行距、文字色和背景色 |
| 滚动/翻页模式 | P1 | EPUB 和 TXT 支持两种模式 |
| 自动翻页 | P2 | 可设置间隔并在失焦时暂停 |

### 5.4 设置与数据

- 设置按本机用户保存。
- 支持设置导出、导入和恢复默认值。
- 支持清除浏览历史、Cookie、缓存、收藏和阅读记录。
- 密码、令牌等敏感数据不得写入普通日志或明文配置。
- 崩溃恢复不能自动重新打开可能含敏感信息的隐藏窗口，需允许用户控制。

## 6. 非功能需求

### 6.1 性能

- 冷启动目标：典型开发机上 3 秒内出现可交互窗口。
- 标签切换：正常页面下无明显阻塞。
- 大型 TXT：解析和索引在工作线程中执行。
- 进度保存：采用防抖，不因每次滚动频繁写盘。

### 6.2 稳定性

- 单个网页标签崩溃不能导致整个应用退出。
- 异常退出后可恢复窗口状态，但默认不自动展示敏感内容。
- 数据结构升级需要版本化迁移和回滚保护。

### 6.3 可访问性

- 核心操作可用键盘完成。
- 文字与交互控件满足基本对比度要求。
- 动效可关闭。
- 快捷键可修改并检测冲突。

## 7. 数据边界

第一阶段只保存：

- 应用设置与窗口状态。
- 收藏、历史和标签会话。
- 本地书籍路径、元数据和阅读进度。
- Chromium 管理的站点 Cookie 与缓存。

第一阶段不建立用户账号，不接入支付，不上传书籍，不做跨设备同步。

## 8. 发布验收

发布候选版本必须通过：

1. macOS Apple Silicon 实机冒烟测试。
2. macOS Intel 或等价构建验证。
3. Windows 10/11 冒烟测试。
4. 全局快捷键冲突与恢复测试。
5. 透明、置顶、隐藏、托盘退出的组合测试。
6. 不可信网页隔离检查。
7. 安装、升级、卸载和数据保留策略检查。
