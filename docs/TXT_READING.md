# TXT 分卷与章节阅读

## 阅读交互

- 导入 TXT 后建立「卷 → 章节」目录，卷可以折叠，章节可以直接跳转。
- 正文只渲染当前章节，不再把整本书铺成一个纵向滚动文档。
- 整章内容连续展示，通过鼠标滚轮、触控板或滚动条上下阅读；不把一章切成多个屏幕页。
- 「翻页」指切换章节。顶部与底部的上一章/下一章，以及正文聚焦后的左右方向键，都直接切换章节并回到目标章开头；首章不能继续向前，末章显示「全书完」。滚动到章末不会自动换章。
- PageUp/PageDown、空格和 Shift+空格保留浏览器原生的章内滚动行为，不切换章节；输入框、按钮和目录保留其原本的键盘行为。
- 搜索仍覆盖全书，查询变化时跳到第一处匹配所在章节并滚动到匹配文字，高亮当前章节的正文、卷名和章名。结果计数仍为全书计数，上限 300。
- 透明外壳与纯文字模式仍会移除阅读纸张及背景；目录弹层保留可读背景，方便操作。

## 字体与排版

- 默认使用舒适黑体，Mac 优先使用系统黑体/苹方，Windows 回退到微软雅黑；可选择书香宋体和系统楷体，缺少某款本机字体时自动回退，不下载外部字体。
- 新安装的推荐排版为 20px 字号、2 倍行距、0.04em 字距（20px 下约 0.8px）。字距可从 0 调整至 0.12em，并随字号同比缩放；0 表示不额外加宽。
- 在设置中查看实时预览，或选择「恢复推荐排版」一键应用上述四项设置；主题、书架和阅读进度不受重置影响。
- 旧设置缺少字体/字距字段时补为舒适黑体和 0.04em，保留用户原有字号与行距；需要全部采用新预设时使用「恢复推荐排版」。设置仅保存到本机，重新打开仍然有效。
- 字体、字距、字号改变后按原章节滚动比例恢复位置，不回到章首。原 TXT、段落和换行不改写，搜索与透明模式继续兼容。

## 识别规则

- 卷级：第一卷/部/篇、卷一、上卷/中卷/下卷，以及 Part/Book/Volume 加数字或罗马数字。
- 章节：第一章、节、回等，中英文数字，Chapter 加数字或罗马数字，以及序章、楔子、番外、后记等。
- 支持 Markdown 标题、CRLF/CR/LF、全角缩进以及「正文 第一章」前缀。
- 空卷标题不额外产生空白页，卷首正文则保留为可读条目。所有区间保留原始文本偏移，不改写原文件。
- 没有识别到章节标题时，按约 6000 字符自动分段，优先选择段落或句末边界，避免截断 CRLF 和 Unicode 代理对；明确显示「自动分段」，不虚构原书章节。
- 识别到的长章节不再人工拆章，完整展示并在章内滚动。

## 阅读位置与兼容性

沿用本地状态格式版本 2 和 `readerPosition: { chapterStart, chapterProgress }`，保存当前章节的原始起点及章内滚动比例。返回设置、浏览网页、重新打开书籍后继续阅读；调整窗口或字体时按章内相对位置恢复。滚动期间合并进度写入，离开阅读视图时立即保存最后位置。短章节全部可见时计为本章已读完。

兼容 v0.1.3 的章节书签：沿用章节起点，将原章内相对页进度映射为章内滚动比例，不清空书架或设置。由于排版方式不同，只能近似恢复原位置。

旧版只保存了整本文档滚动百分比，没有字符级书签，因此首次升级只能按原百分比映射到大致章节位置，不能精确还原旧版某一行；不会把旧进度直接归零。之后使用新的章节书签。无效书签忽略或拒绝，原书架及设置保留；原始 TXT 不修改、不上传。

## 验证

单元测试覆盖卷分组、卷首正文、无标题自动分段、字符完整性、书签持久化、旧进度迁移、章内滚动比例与跨章总进度，以及字体/字距默认值、旧设置补全、零字距持久化与非法值校验。真实 Chromium 交互测试覆盖整章滚动、切章与首末章边界、键盘滚动、目录跳转、搜索定位、重挂载恢复、字体/字距/窗口变化、设置预览和透明模式。

运行 `npm test`、`npm run test:reader` 和 `npm run build`。交互测试使用独立临时用户目录，不读取或修改用户实际书架。
