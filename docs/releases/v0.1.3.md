# Stealth Reader v0.1.3（预发布）

TXT 小说分卷、分章与分页阅读。本版本以独立版本发布，不替换 v0.1.2，也不进入正式版 latest 自动更新通道。

## 新功能

- 自动建立「卷 → 章节」目录，支持折叠卷、直接跳章和上一章/下一章。
- 正文只加载当前章节；章内根据窗口大小、字号、行距分页，不再将整本 TXT 铺成纵向长文档。
- 支持上一页/下一页、左右方向键、PageUp/PageDown 和空格翻页。章末衔接下一章，章首页向前翻可返回上一章末页。
- 无章节标题时按约 6000 字符自动分段，优先选择段落或句末，保留原始文本，不虚构书中章节。
- 记录章节及章内位置，切换网页、设置或重新打开后继续阅读；字号和窗口变化时自动重排。
- 全书搜索可跨卷、跨章定位到匹配页，支持正文、卷名、章名高亮。
- 继续兼容纯文字透明模式和透明窗口外壳。

## 安装与数据兼容

- 覆盖安装前先从菜单/托盘退出旧程序；Windows 安装版沿用原安装路径，免安装版退出后替换旧文件。
- Mac 下载 DMG 后将应用拖入「应用程序」覆盖。保留免费的 ad-hoc 临时签名，未做 Apple Developer ID 签名/公证；首次下载仍可能需要在「系统设置 → 隐私与安全性」手动允许。不关闭 Gatekeeper，不自动移除 quarantine。
- 书架与设置保留，不改写、不上传原始 TXT。原书无需重新导入。
- 本地状态升级到版本 2，增加可选章节书签。旧版只有整本文档的滚动百分比，因此首次升级只能映射到大致章节位置，无法精确还原旧版某一行；之后会保存新的章内位置。
- 当前仍为预发布，需要手动下载安装，不会在正式客户端提示自动更新。

- 103 项测试覆盖章节解析、分卷、自动分段、文本完整性、只渲染当前章节、搜索高亮、书签及旧进度兼容等。

- 本机 macOS 已验证分卷目录、长短章节翻页、跨章前后衔接、搜索、透明模式、重开恢复及字号重排。Windows 安装器覆盖安装的手动交互仍需 Windows 设备验证。
