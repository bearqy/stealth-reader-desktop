# Stealth Reader v0.1.2（预发布）

相关代码已通过 PR #3 合并。本次安装包保留原 CI 构建内容，仅统一附件命名；原始构建提交和 SHA-256 不变。此 Release 仍保留预发布状态，不会推送给正式版客户端。

## 新功能与修复

- TXT 跟随纯文字透明模式或透明窗口外壳，移除阅读纸张、主题背景、边框和阴影。
- 自动识别中英文章节、卷、节、序章和番外等标题，提供章节目录、当前章节与上一章/下一章跳转。
- 修复切换设置或网页后本地书籍阅读位置回退的问题。
- 设置和系统托盘增加软件更新入口，可选择启动时检查 GitHub Releases。
- 根据系统、芯片架构和安装类型匹配安装包，支持下载进度、取消、重试与 SHA-256 校验；校验失败不启动安装。

## 下载

| 平台 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `StealthReader-0.1.2-macos-arm64.dmg` |
| macOS Intel | `StealthReader-0.1.2-macos-x64.dmg` |
| Windows x86_64 安装版 | `StealthReader-0.1.2-windows-x64-setup.exe` |
| Windows x86_64 免安装版 | `StealthReader-0.1.2-windows-x64-portable.exe` |

附件 `SHA256SUMS.txt` 提供校验值，`BUILD_INFO.json` 记录构建来源和提交。

## 安装与更新

- 已安装的旧版需要先手动覆盖安装一次 v0.1.2，之后可以使用应用内更新入口。
- Windows 安装版启动覆盖安装后退出旧程序；免安装版下载后需退出程序，再手动替换旧文件。
- macOS 下载后打开 DMG，并将应用拖入「应用程序」覆盖旧版；当前未做 Apple Developer ID 签名/公证，不支持静默替换。
- 安装包尚未进行商业代码签名，系统可能显示安全提示；请确认下载来源及文件摘要。
- 书架、阅读进度与本地设置沿用原用户数据，不需要删除用户数据。
- Windows 系统级覆盖安装与 macOS Intel 的实际交互仍需对应设备验证；CI 会在原生系统上完成测试、构建与包内容校验。
