# Stealth Reader v0.1.2（预发布）

相关功能代码已通过 PR #3、PR #4 合并。macOS 安装包重新构建，补全免费 ad-hoc 临时签名，修复原始发布包因签名无效而提示「已损坏」的问题；Windows 安装包保持不变。此 Release 仍保留预发布状态，不会推送给正式版客户端。

## 新功能与修复

- TXT 跟随纯文字透明模式或透明窗口外壳，移除阅读纸张、主题背景、边框和阴影。
- 自动识别中英文章节、卷、节、序章和番外等标题，提供章节目录、当前章节与上一章/下一章跳转。
- 修复切换设置或网页后本地书籍阅读位置回退的问题。
- 设置和系统托盘增加软件更新入口，可选择启动时检查 GitHub Releases。
- 根据系统、芯片架构和安装类型匹配安装包，支持下载进度、取消、重试与 SHA-256 校验；校验失败不启动安装。

## 安装与更新

- 已安装的旧版需要先手动覆盖安装一次 v0.1.2，之后可以使用应用内更新入口。
- Windows 安装版启动覆盖安装后退出旧程序；免安装版下载后需退出程序，再手动替换旧文件。
- macOS 下载后打开 DMG，并将应用拖入「应用程序」覆盖旧版；当前未做 Apple Developer ID 签名/公证，不支持静默替换。
- macOS 使用免费的 ad-hoc 临时签名，未做 Apple Developer ID 签名或公证；首次打开仍可能需要在「系统设置 → 隐私与安全性」中手动允许。无需关闭系统安全检查。Windows 仍未进行商业代码签名。
- 书架、阅读进度与本地设置沿用原用户数据，不需要删除用户数据。
- 两种 macOS 架构的 CI 增加最终 DMG 签名校验、独立用户目录启动与界面/preload/IPC 检查；ARM64 另做本机验证。Windows 系统级覆盖安装与 Intel 手动安全放行仍需对应设备验证。
- macOS 重新发布后请重新下载同名 DMG，旧下载文件不会自动修复；最新摘要与各平台构建来源见附件。签名方案与验证步骤见 `docs/MACOS_SIGNING.md`。
