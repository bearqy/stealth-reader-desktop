# Stealth Reader v0.1.5（预发布）

优化导入 TXT 的字体与字距，增加可调排版、即时预览和一键推荐方案。本版本用于 PR 合并前验证，不替换正式最新版 v0.1.4，也不进入正式客户端的 latest 更新通道。

## 阅读排版优化

- 新增舒适黑体、书香宋体与系统楷体选择，替代原先固定的宋体；使用本机字体，缺失时自动回退，不联网下载或打包商业字体。
- 新安装的推荐排版为 20px 字号、2 倍行距、0.04em 字距，20px 下约为 0.8px。
- 字距可在 0～0.12em 间调整，随字号同比缩放；0 表示不额外加宽。
- 设置中新增实时排版预览和「恢复推荐排版」按钮，方便比较字体、字号、行距与字距。
- 已有用户保留原字号、行距、主题与书签，自动补全新增字体与字距设置；若想完整使用新预设，可点击「恢复推荐排版」。
- 调整字体和字距后继续按原章节滚动比例恢复，不回到章首；保留全书搜索、透明阅读与章内滚动/翻页换章。
- 所有排版设置仅保存到本机，不改写 TXT 原文件，不影响网页字体。

本方案参考番茄公开网页版的系统字体回退和正文行高，为独立的桌面舒适预设，不宣称复刻番茄移动 App 的字体或字距参数。来源与说明见 `docs/TXT_READING.md`。

## 安装与兼容性

- 覆盖安装前从菜单或托盘退出旧程序，保留书架、设置、阅读进度和原始 TXT，无需重新导入书籍。
- Mac 将 DMG 中的应用拖入「应用程序」覆盖。继续使用免费的 ad-hoc 临时签名，未做 Apple Developer ID 签名或公证；首次下载可能仍需在「系统设置 → 隐私与安全性」允许打开。不关闭 Gatekeeper，不移除 quarantine。
- Windows 安装版沿用原路径，免安装版退出后替换旧文件；Windows 程序尚未做商业代码签名。
- 当前为预发布，需要手动下载安装；正式版客户端不会检查到 v0.1.5。

## 验证范围

- 114 项单元测试，覆盖新排版默认值、旧设置兼容、字距校验和持久化、设置预览，以及章节、书签、搜索与更新策略等。
- 三平台原生 CI 执行 Chromium 交互验证、类型检查、生产构建和包内内容一致性检查。
- 阅读交互验证覆盖字体/字距切换后的滚动位置、零字距、预览和推荐方案、设置布局，并继续检查滚动、切章、搜索、书签、透明模式等。
- 最终 Mac DMG 执行镜像完整性、deep/strict 签名检查，以及安装副本的启动、界面和 preload/IPC 检查。
- Windows 安装器覆盖安装的手动交互仍需 Windows 设备验证；原生构建与阅读界面测试不等同于覆盖安装测试。
