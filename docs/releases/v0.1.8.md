# Stealth Reader v0.1.8

## 后台检查更新

- 正式安装版默认在启动后 30～45 秒检查，成功后约每 6 小时检查一次。
- 断网、超时或请求受限时在后台逐步降低重试频率，不弹窗、不打断阅读，也不清除已发现的新版。
- 发现可用新版只更新侧栏提示，不会自动下载或安装。设置页和系统托盘仍保留手动检查。
- 设置中的「自动检查更新」可随时关闭；以前已关闭启动检查的用户会保留关闭状态。

## 下载

| 平台 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `StealthReader-0.1.8-macos-arm64.dmg` |
| macOS Intel | `StealthReader-0.1.8-macos-x64.dmg` |
| Windows x64 安装版 | `StealthReader-0.1.8-windows-x64-setup.exe` |
| Windows x64 免安装版 | `StealthReader-0.1.8-windows-x64-portable.exe` |

- Mac v0.1.6 及更新版本可在下载后选择「重启并安装更新」，v0.1.5 及更早版需要手动覆盖一次。
- Windows 安装版使用覆盖安装，免安装版需退出后手动替换文件。
- Mac 安装包使用 ad-hoc 签名，未做 Apple Developer ID 签名或公证；Windows 安装包未做商业代码签名。
- `Stealth-Reader-*` 是旧更新器的兼容副本。附件摘要和构建来源见 `SHA256SUMS.txt`、`BUILD_INFO.json`。
