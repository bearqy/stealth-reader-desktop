# Stealth Reader v0.1.7

## TXT 阅读体验

- 打开章节目录时，自动把当前章滚动到可见位置并高亮。点选当前章继续阅读，不会重置章内进度。
- 「上一章 / 下一章」居中放在正文末尾，随正文滚动。读完可以就近切章，左右方向键切章仍可使用。
- 继续使用已有书架和阅读书签，无需重新导入 TXT。

## 下载与更新

| 平台 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `StealthReader-0.1.7-macos-arm64.dmg` |
| macOS Intel | `StealthReader-0.1.7-macos-x64.dmg` |
| Windows x64 安装版 | `StealthReader-0.1.7-windows-x64-setup.exe` |
| Windows x64 免安装版 | `StealthReader-0.1.7-windows-x64-portable.exe` |

- 在设置中选择「检查更新」。Mac v0.1.6 可下载后选择「重启并安装更新」；Mac v0.1.5 及更早版仍需手动安装一次。
- Windows 安装版使用覆盖安装；免安装版需退出后手动替换。
- Mac 安装包使用 ad-hoc 签名，未做 Apple Developer ID 签名或公证；Windows 安装包未进行商业代码签名。
- `Stealth-Reader-*` 是给旧更新器保留的兼容副本，手动下载请选择上表的标准文件名。附件摘要和构建来源见 `SHA256SUMS.txt`、`BUILD_INFO.json`。
