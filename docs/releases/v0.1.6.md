# Stealth Reader v0.1.6（预发布）

本版包含 TXT 分章修复和 Mac 应用内重启安装更新。用于 PR 合并前验证，不替换正式最新版 v0.1.5，不进入正式客户端的 latest 更新通道。

## TXT 分章修复

- 修复标题含问号、感叹号时漏分章的问题，例如「第三百六十三节：幽魂？幽魂！」现在会独立成章，不再并入上一章。
- 兼容中英文标点、数字、全角缩进和 Markdown 标题；保留短标题、章节前缀及正文过滤规则。
- 目录、上一章/下一章及全文搜索使用修正后的章节索引；原 TXT 和换行不修改，重新打开已有书籍即可，无需删除后重新导入。
- 如果旧书签来自原先被合并的章节，且全书位置已落到新识别的后续章节，则按保存的全书进度近似恢复；章末书签不会自动跳到下一章。

## Mac 重启并安装更新

- 下载完成后点击「重启并安装更新」，自动校验、预置新应用、退出旧进程、替换并重新打开，不再要求手动拖拽。
- 验证附件大小/SHA-256、DMG 完整性、应用标识、版本、CPU 架构、可执行文件名与 deep/strict 签名；已有正式签名团队时要求同团队。
- 新界面完成 bootstrap 后确认启动；启动失败时尝试恢复旧版，保留诊断信息。准备期间目标被其他安装器改动时停止替换。
- 保留当前用户数据目录、书架、设置、阅读进度和原 TXT；不请求管理员密码、不关闭 Gatekeeper、不删除 quarantine。
- 不支持从只读磁盘映像、App Translocation 或不可写安装目录原位更新；系统安全策略仍可能要求手动允许，不能承诺完全无人值守。

**首次迁移：v0.1.5 及更早的 Mac 客户端仍需要最后手动安装一次 v0.1.6。旧程序无法通过服务端设置获得新更新代码；安装本版后，后续正式版本才可使用「下载 → 重启并安装更新」。**

Windows 保持原有 NSIS 安装交接和 portable 手动替换方式，本次未改变 Windows 安装策略。

## 安装与验证边界

- 当前为预发布，需手动下载安装。Mac 将应用拖入「应用程序」覆盖；Windows 安装版保持原路径，portable 退出后替换文件。
- Mac 继续使用免费的 ad-hoc 临时签名，未做 Apple Developer ID 签名或公证；首次下载可能仍需在「系统设置 → 隐私与安全性」允许打开。签名完整性和 SHA-256 不等于 Apple 发布者认证。Windows 尚未做商业代码签名。
- 回滚不是断电保护：断电或强制终止安装助手时可能需要从私有更新目录的 `previous.app` 恢复或重新安装，不应删除用户数据目录。
- 本机 148 项测试通过，包含分章回归、旧书签兼容、更新状态机与 Mac 原生签名测试应用的替换/回滚/目标变更保护；Windows 会跳过 Mac 专项测试。
- Mac ARM64/Intel CI 额外执行真实隔离 Electron 应用的替换、重启、React/preload 启动确认及用户数据保留验证。此测试使用当前构建的隔离副本，不表示旧版 v0.1.5 已具备自动替换能力。
- 三平台执行测试、阅读交互、类型检查、生产构建与包内内容一致性验证；最终 Mac DMG 另做镜像、deep/strict 签名和安装副本启动检查。
- Windows 安装器覆盖安装的手动交互仍需 Windows 设备验证。

完整说明见 `docs/TXT_READING.md`、`docs/UPDATES.md` 和 `docs/MACOS_SIGNING.md`。
