# Stealth Reader v0.1.4（预发布）

修正 TXT 阅读交互：整章上下滚动，「翻页」直接切换章节，不再将一章拆为多个屏幕页。本版本用于 PR 合并前验证，不替换正式最新版 v0.1.3，也不进入正式客户端的 latest 更新通道。

## 阅读体验修正

- 只渲染当前章节的完整正文，支持鼠标滚轮、触控板及滚动条上下阅读。
- 顶部、底部的上一章/下一章按钮和正文聚焦后的左右方向键，直接切换章节并回到目标章开头。
- 滚到章末不会自动跳章；首章禁用上一章，最后一章显示「全书完」。
- PageUp/PageDown、空格和 Shift+空格保留浏览器原生的章内滚动行为。
- 保存当前章节与章内滚动比例，离开阅读界面时保存最后位置；调整窗口和字号后按比例恢复。
- 兼容 v0.1.3 的章节书签，原相对页进度映射为章内滚动比例，因此首次切换排版后的位置是近似值，不清空书架或设置。
- 全书搜索跳转到匹配所在章节，并将匹配文字滚动到可见位置；保留分卷目录和透明阅读模式。
- 移除书籍时不再尝试保存已移除书籍的待写入进度。

## 安装说明

- 覆盖安装前从菜单或托盘退出旧程序，保留现有书架、设置和 TXT 原文件。
- Mac 将 DMG 中的应用拖入「应用程序」覆盖。继续使用免费的 ad-hoc 临时签名，未做 Apple Developer ID 签名或公证；首次下载可能仍需在「系统设置 → 隐私与安全性」允许打开。不关闭 Gatekeeper，不移除 quarantine。
- Windows 安装版沿用原路径；免安装版退出后替换旧文件。Windows 程序尚未做商业代码签名。
- 当前为预发布，需手动下载安装；正式版客户端不会检查到 v0.1.4。

## 验证范围

- 105 项单元测试，覆盖章节解析、书签、垂直滚动进度、只渲染当前章和旧进度兼容等。
- 三平台原生 CI 执行 Chromium 阅读交互验证、类型检查、生产构建与包内构建内容一致性检查。
- 阅读交互验证包括真实鼠标滚轮、PageDown/空格滚动、按钮/方向键切章、章末不跳章、目录、搜索、旧书签恢复、窗口/字号变化及透明模式。
- 最终 Mac DMG 执行镜像完整性、deep/strict 签名检查，以及安装副本的启动、界面和 preload/IPC 检查。
- Windows 安装器覆盖安装的手动交互仍需 Windows 设备验证；原生构建与阅读界面测试不等同于安装器覆盖安装测试。

完整交互规则见 `docs/TXT_READING.md`。
