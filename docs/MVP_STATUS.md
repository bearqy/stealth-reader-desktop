# 本地 MVP 实现状态

更新日期：2026-08-10

## 已完成的第一条可运行链路

### 桌面壳

- Electron + TypeScript + React + Vite 工程。
- macOS 实际启动与窗口渲染验证。
- 窗口置顶和透明度调节。
- 左侧功能栏可由设置或水滴按钮收起，并保留窄控制轨快速恢复。
- 网页图片、背景图和视频画面可由设置或快捷按钮即时隐藏与恢复。
- macOS 与 Windows 原生透明纯文字模式可移除媒体、背景、边框与阴影，让网页文字悬浮在下层应用画面上。
- 可选透明窗口外壳，覆盖应用根背景、设置页背景、标题栏、侧栏、顶部工具栏和网页滚动条；macOS 同时隐藏窗口阴影，Windows 使用透明标题栏覆盖层保留原生最小化、最大化和关闭按钮。
- 透明外壳下的侧栏控制按钮使用低干扰轮廓样式；完整侧栏预留按钮间距，窄窗口自动改为两行排列，避免 Windows 显示缩放下裁切水滴按钮。
- 设置保存通知位于网页视图外的侧栏点击区域，可手动关闭；侧栏收起时仅显示轮廓关闭按钮。
- 可选的鼠标移出完全隐身：鼠标离开窗口范围时降至 0% 透明度，移回后恢复。
- 顶部工具栏可通过持久化开关手动收起和恢复，不跟踪鼠标。
- macOS 顶部菜单栏常驻自适应小图标，左键或右键可打开「显示程序 / 退出程序」菜单。
- 全局老板键，默认 `CommandOrControl+Shift+H`。
- 快捷键冲突回滚。

### 安全网页标签

- 使用 WebContentsView 管理多标签。
- 地址输入、关键词搜索、前进、后退和刷新。
- 网页视图尺寸同步、自适应窗口缩放和手动缩放控制。
- 内置微信读书、抖音、哔哩哔哩、小红书、粉笔网、番茄小说和晋江文学城入口。
- 只允许 HTTP/HTTPS 导航。
- 网页标签禁止 Node.js，启用 context isolation 和 sandbox。
- 网页权限默认拒绝。
- 弹窗在受控新标签中打开。
- 网页标签崩溃与应用界面隔离。

### 本地 TXT 阅读

- 文件选择与 32MB 安全上限。
- UTF-8、UTF-8 BOM、UTF-16 LE/BE、GB18030 自动识别。
- 本地书架和文件元数据。
- 阅读进度防抖保存与恢复。
- 文档内搜索，最多高亮前 300 个结果。
- 字号、行距、纸张/护眼/暗色主题。
- 源文件路径不暴露给渲染界面。

### 工程保障

- TypeScript strict mode。
- 生产构建。
- 默认站点、跨平台窗口外壳、工具栏手动收起、纯文字模式、媒体隐藏、侧栏收起、网页缩放、窗口隐身、URL 安全、特权窗口导航、文本编码和本地状态共 36 项自动化测试。
- npm 依赖锁定，审计结果为 0 个已知漏洞。
