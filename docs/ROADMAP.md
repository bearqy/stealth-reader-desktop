# 交付路线图

路线图描述依赖关系和完成标准，不承诺固定日期。

## M0：产品与工程准备

状态：进行中

- [x] 确定产品核心方向。
- [x] 定义本地优先 MVP。
- [x] 起草技术架构。
- [x] 起草安全与隐私基线。
- [x] 起草开发规范。
- [ ] 确定正式产品名与仓库名。
- [ ] 确认 macOS 最低版本。
- [ ] 确认支持的首批文档格式。
- [ ] 评审 Electron 安全边界。
- [ ] 将范围拆分为 Issues 和里程碑。

完成标准：范围无关键歧义，可以开始创建应用脚手架。

## M1：桌面壳与窗口能力

- Electron、TypeScript、React 基础工程。
- 主进程、preload、renderer 边界。
- 窗口置顶、透明度和迷你模式。
- 托盘与全局老板键。
- 窗口状态安全恢复。
- macOS arm64 与 Windows 开发构建。

完成标准：不包含浏览与阅读功能，也能稳定验证系统级窗口体验。

## M2：安全网页浏览 MVP

- 地址栏和导航。
- WebContentsView 多标签。
- 历史、收藏和会话恢复。
- 缩放与移动端模式。
- 权限、弹窗、协议和下载策略。
- 标签崩溃隔离。

完成标准：常见内容站点可以使用，不可信网页无法访问桌面能力。

## M3：本地阅读 MVP

- TXT、EPUB、PDF 导入与书架。
- 目录、搜索、进度。
- 字体、字号、行距和主题。
- 滚动与翻页基础体验。
- 大文件 worker 解析。

完成标准：三种首发格式在 macOS 与 Windows 上均可稳定完成核心阅读流程。

## M4：隐蔽体验完善

- 鼠标移出隐藏。
- 自动滚动和速度控制。
- 页面配置预设。
- 防截屏尽力而为实现。
- 快捷键冲突诊断。
- 多显示器、全屏空间和休眠恢复。

完成标准：系统级能力组合测试通过，不会出现窗口无法恢复。

## M5：发布准备

- 安装、升级和卸载。
- macOS 签名与公证。
- Windows 代码签名。
- 安全更新通道。
- 崩溃日志本地导出。
- 隐私政策、使用条款和用户文档。

完成标准：可向小范围测试用户发布。

## 后续候选

- MOBI/AZW3 完整支持。
- 多配置文件。
- 加密备份与可选同步。
- 账号和会员体系。
- 写作、协作或 AI 功能。

这些候选不进入第一阶段承诺，需单独完成需求和隐私评审。
